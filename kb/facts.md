- Plans (source: https://arize.com/docs/ax/security-and-settings/pricing-and-usage): AX Free includes 25k spans per month, 1 GB storage and 15 days of retention. AX Pro includes 50k spans per month, 10 GB storage and 30 days of retention. AX Enterprise has custom span volume, storage and retention. Every plan has unlimited users, evaluations, experiments, datasets and prompts.
- Enterprise SSO is only on AX Enterprise, not Free or Pro (source: https://arize.com/docs/ax/security-and-settings/pricing-and-usage).
- Per-space rate limiting (monthly caps per space) is an Enterprise, opt-in feature; only Arize can change the annual contract limit (source: https://arize.com/docs/ax/security-and-settings/space-rate-limiting).
- Python tracing setup: pip install arize-otel plus the OpenInference instrumentor for the framework (for LangChain: openinference-instrumentation-langchain); call register(space_id=..., api_key=..., project_name=...) and then LangChainInstrumentor().instrument(tracer_provider=tracer_provider). Credentials usually come from ARIZE_SPACE_ID and ARIZE_API_KEY; ARIZE_PROJECT_NAME sets the project (source: https://arize.com/docs/ax/integrations/python-agent-frameworks/langchain/langchain-tracing).
- No manual spans are needed for LangChain: auto-instrumentation captures chains, LLM calls, retrievers and tools; manual spans are optional for custom code (source: https://arize.com/docs/ax/instrument/combining-auto-and-manual).
- TypeScript/JavaScript is supported with @arizeai/openinference-instrumentation-* packages plus the OpenTelemetry Node SDK and an OTLP exporter; Java is supported too (LangChain4j, Spring AI) (source: https://arize.com/docs/ax/integrations/llm-providers/openai/openai-tracing).
- arize-otel uses a non-blocking BatchSpanProcessor by default; register(..., batch=False) switches to a SimpleSpanProcessor, which is handy for debugging (source: https://arize.com/docs/ax/instrument/configure-your-tracer).
- EU data residency: pass endpoint=Endpoint.ARIZE_EUROPE to register(); the default endpoint is otlp.arize.com (source: https://arize.com/docs/ax/instrument/configure-your-tracer).
- Masking sensitive data: OpenInference environment variables such as OPENINFERENCE_HIDE_INPUTS, OPENINFERENCE_HIDE_OUTPUTS, OPENINFERENCE_HIDE_INPUT_MESSAGES, OPENINFERENCE_HIDE_OUTPUT_MESSAGES and OPENINFERENCE_HIDE_EMBEDDING_VECTORS keep prompts and outputs out of traces (source: https://arize.com/docs/ax/instrument/mask-and-redact-data).
- Sessions: group a multi-turn conversation by setting session.id, e.g. `with using_session(session_id="..."):` from openinference.instrumentation; using_user sets user.id (source: https://arize.com/docs/ax/instrument/set-up-sessions).
- Compliance: Arize holds SOC 2 Type II, PCI DSS 4.0 and HIPAA certifications (source: https://arize.com/docs/ax/security-and-settings/compliance).
- Deleting sensitive traces that were already sent is supported (source: https://arize.com/docs/ax/security-and-settings/compliance/delete-traces-with-sensitive-data).
- API keys: in the Arize app go to Settings → API Keys and click + New API Key; the full key is shown only once, so copy it right away (source: https://arize.com/docs/ax/security-and-settings/api-keys).
- LangGraph is traced with the same OpenInference LangChain instrumentor: install arize-otel, then LangChainInstrumentor().instrument(tracer_provider=tracer_provider); every graph node, tool call and LLM call is captured (source: https://arize.com/docs/ax/integrations/python-agent-frameworks/langgraph/langgraph-tracing).
- PCI DSS 4.0 matters for e-commerce teams handling payment data; Arize is PCI DSS 4.0 certified (source: https://arize.com/docs/ax/security-and-settings/compliance).
